## VisDrone consecutive-frame probe (near_duplicate)

Consecutive frames (sorted by name) within each VisDrone2019-DET-val sequence, all 76 sequences; not planted, so every flag is a natural near-duplicate. Of 472 consecutive pairs, the frozen two-stage rule flags 59 (12.5%) and the pHash-only fallback flags 27 (5.7%). A quick visual check of the highest-distance flagged pairs (Hamming 22, cosine 0.92-0.93) shows the same street scene with the drone slightly moved. That is redundant footage, not a contributor copy. The evaluation batch takes only the first and last frame of each sequence, so few of these pairs are in it; a batch built from consecutive frames would see about one in eight neighbouring frames flagged.
